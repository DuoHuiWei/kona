# 独立预处理材料生产与分发实验目录

建立日期：2026-11-05。

本目录用于 ConstantPP、Shao、SecKNN、Kona、Ours 五个方案的预处理材料生产与分发实验。2026-11-05按用户要求由 `kona-offline-online-exp/` 改名，去掉方案前缀。旧工程的在线协议、调用和已有实验记录保持原样；不把在线流程搬入这里。当前只有静态清单和库复用调查，尚无新实现或可运行入口，也没有新建 Docker 环境。

## 当前资料

- [五方案现成实现复用清单](library_reuse.md)：哪些底层协议已有，哪些需要适配或组合。
- [本次材料需求与缺口清单](material_requirements.md)：从文档目录迁入，先确认缺什么，具体数量暂缓核算。
- [已有材料审计](../docs/offline_materials_audit.md)：已有公式、格式、实现入口及五方案背景，保留原位置供参考。

## 后续收纳范围

确认生成方案后，把欧氏距离关联材料、算术 MUL 三元组、布尔 AND 三元组、DCF 密钥及关联掩码、ConstantPP洗牌关联材料、Shao的NHSS准备适配集中放在本目录；再补分发、消费标识和实验计量入口。NHSS输入编码与查询token单列为依赖输入的准备。

后续新增的材料生产源码、库适配、依赖版本记录、构建入口、实验脚本和输出都放在本目录下面，按实际需要建子目录；优先引用已有可靠组件，保持上级工程源码和Makefile不变。当前没有下载第三方代码或安装依赖。

独立实验测的是指定材料清单的真实生成与分发成本。文件加载需单列；这里的结果不能与历史在线时间相加后标成单独实测端到端时间。
